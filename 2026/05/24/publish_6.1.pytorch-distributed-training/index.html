PyTorch CUDA 入门（扩展）：分布式训练与推理

引言：从单 GPU 到多 GPU 集群

现代大模型需要大量 GPU 同时运行。假设我们有2 台服务器，每台 4 GPU——共 8 个 GPU，需要协调工作。

PyTorch 通过 torch.distributed 支持多节点分布式训练和推理。

分布式核心概念

进程组模型

每个 GPU 对应一个进程，这些进程组织成进程组：

概念 说明
rank 当前进程在全局中的编号（0 ~ world_size-1）
world_size 总进程数（即总 GPU 数）
local_rank 当前服务器内的 GPU 编号（0~3）
group 进程的子集，用于部分 GPU 通信

总计：8 个进程，world_size=8

后端选择

torch/distributed/distributed_c10d.py:257-307

NCCL：NVIDIA 的跨 GPU 通信库，专门优化了多节点 GPU 通信。

服务器如何找到彼此？

torchrun --nnodes=2 不会自动发现其他服务器，需要显式配置。

核心参数

参数 说明
--rdzv_id 任务唯一标识，相同任务的不同进程用同一个 ID
--rdzv_endpoint rendezvous 服务器地址（通常是主节点 IP:端口）
--nnodes 总节点数
--nproc_per_node 每台服务器的进程数
