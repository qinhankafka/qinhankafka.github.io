Placement New：只在指定地址构造对象

普通的 new 和 delete

在 C++ 中，我们通常这样使用 new 和 delete：

new 运算符做了两件事：

  1. 分配内存——从堆上获取一块足够大的空间
  2. 构造对象——在这块内存上调用构造函数

delete 运算符也做了两件事：

  1. 析构对象——调用析构函数
  2. 释放内存——把内存归还给堆

Placement New 是什么？

Placement new 是一种特殊的 new 语法，它只执行构造，不分配内存。

语法是 new (地址) Type(args)，意思是：**”在给定的地址上构造一个 Type 对象”**。

完整的生命周期管理

Placement new 只负责构造，析构需要手动调用：

这与普通 new/delete 不同：

  • new 同时负责构造和内存分配
  • delete 同时负责析构和内存释放
  • placement new 只负责构造
  • 需要手动调用析构函数，但不需要（也不能）释放内存

总结

Placement new 是 C++ 提供的一种灵活构造语法：

  • 核心作用：在预分配的内存上构造对象，不分配内存
  • 语法：new (地址) Type(args)
  • 使用场景：Python/C 互操作、内存池、固定地址对象
  • 注意事项：析构需手动调用，内存管理由程序员控制

当你需要”在指定位置构造对象”而不是”分配一块新内存再构造”时，placement new 就是正确的选择。
